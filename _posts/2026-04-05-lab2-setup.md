## Problem Statement 
**Malware** remains one of the most prevalent threats in cybersecurity. Security analysts must be able to triage suspicious files quickly determining whether a file is malicious, what it does, and how it operates without running it in a production environment. This lab introduced the foundational techniques and tools for static malware analysis.

### Approach
The lab covered the malware analysis pipeline from triage to deep inspection:

1. **Campaign Awareness** — Reviewed real-world malware case studies (Stuxnet, WannaCry) to understand targeted vs. mass campaign attack styles.
2. **Attack Identification** — Mapped the two essential steps of a malware attack (Delivery → Execution) and the two signature categories used to identify infections (Host-Based and Network-Based).
3. **MD5 Checksumming** — Generated MD5 hashes for sample executables (`aws.exe`, `Netlogo.exe`, `vlc.exe`) to create file fingerprints.
    ![MD5](assets/img/md.jpg)
4. **VirusTotal Lookup** — Submitted hashes to VirusTotal to check if the files had prior malicious detections.
5. **Packer Detection with PeID** — Used PeID and pestudio to detect whether executables were packed or obfuscated, identifying FSG 1.0 as the packer for one sample.
6. **String Extraction** — Used Sysinternals `strings` to extract human-readable artifacts from binaries, uncovering embedded URLs and other indicators.
7. **Import Analysis** — Examined PE imports using pestudio and IDA Freeware to map what Windows APIs a binary calls, revealing its intended behavior.
![MD5](assets/img/pe.jpg)
8. **Practical Summary** — Performed end-to-end triage on `ComplexCalculator.exe`, confirming it as malicious via VirusTotal.
![MD5](assets/img/cc.jpg)


### Tools Used
1. **HashTab** - File hash (MD5) generation via Windows properties 
2. **VirusTotal** - Cloud-based multi-engine malware hash/file lookup 
3. **PeID** - Packer and compiler detection for PE executables 
4. **pestudio** - Static PE file analysis and import review 
5. **Sysinternals Strings** - Extracting readable strings from binaries 
6. **IDA Freeware** - Disassembly and import table analysis 


### Lessons Learnt
- **MD5 checksums serve as rapid triage indicators** — a known-bad hash immediately flags a file without needing to run it.
- **VirusTotal aggregates dozens of AV engines**, making it far more reliable than any single scanner for initial triage.
- **Packers and obfuscation are common evasion techniques** — a file flagged as packed by PeID warrants deeper investigation even if AV doesn't flag it.

- The two phases of every malware attack
**Delivery and Execution** — are the key intervention points for defenders to break the kill chain.
