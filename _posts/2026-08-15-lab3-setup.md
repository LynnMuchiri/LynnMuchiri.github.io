## Executive Summary
A suspected malware infection affects Eric Fischer, a purchasing department employee of Bartell Ltd. He received a Word document attachment from a known contact and enabled its content, which resulted in suspicious outbound network activity from his workstation. After identifying the activity, the SOC sent out an endpoint alert and obtained a packet capture (PCAP) for additional analysis. This investigation's goals were to examine network data, identify malicious behaviour, identify the infrastructure and systems involved, and create indications of compromise (IOCs).

## Scope & Data Sources

The investigation focused on the network activity generated by Eric Fischer's workstation after he opened the Word document and enabled its content. The primary source of evidence was the packet capture (PCAP) retrieved from the network sensor by the SOC.

I analyzed the PCAP using Wireshark, focusing on HTTP traffic, network streams, server responses, IP addresses, domains, HTTP headers, post-infection traffic, and SMTP traffic.

The investigation covered:

- HTTP requests and responses
- Malicious file downloads
- HTTP server and response headers
- IP addresses and domain names
- Cobalt Strike infrastructure
- Post-infection communication
- Data sent from the victim to the C2 server
- SMTP traffic
- Information gathered by the malware about the victim

## Investigation & Analysis

### First HTTP Connection

I started the investigation by applying an HTTP filter in Wireshark to identify the first malicious outbound connection from the victim's workstation.

The first malicious HTTP GET request was identified at:

`2021-09-24 16:44:38`

This provided the initial timestamp for the malicious network activity observed after the user enabled content in the Word document.

### Suspicious Download

I then followed the relevant HTTP stream to investigate the data being transferred from the external server.

The traffic revealed that the victim's workstation was pulling a ZIP archive named:

`download.zip`

The domain serving the malicious file was identified as:

`attirenepal.com`

I examined the HTTP response and the hexadecimal data associated with the transfer to identify the file contained within the archive. The file name identified was:

`chart-1530076591.xls`

This showed that the suspicious outbound network activity was associated with the retrieval of a file disguised as an Excel document.

### Web Server Analysis

Further analysis of the server information revealed that the web server hosting the malicious content was:

`LiteSpeed`

The server also exposed the following PHP version:

`PHP/7.2.34`

The server headers provided additional information about the infrastructure involved in hosting the malicious file.

### SSL Certificate

The SSL certificate associated with the first domain was identified as being signed by:

`GoDaddy`

This was documented as part of the infrastructure information identified during the investigation.
